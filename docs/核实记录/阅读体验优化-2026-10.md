## 范围和设计

沿用现有 53 节、静态 HTML、Markdown 正文和离线构建。
保留黑白主色、HP 绿、MP 蓝和默认暗色。
正文补充放在第 23、44、52 节，并附《AI 时代的学习与职业选择》长文。
研究结论、任务能力评估和作者建议分别写清。
就业暴露比例不当成裁员比例。作品集方法不承诺就业收益。

界面采用“概览 → 搜索筛选 → 条目细读 → 长文解释”的阅读顺序。
不改变现有条目成本计算和章节永久编号。

## 信息架构诊断

| 问题 | 当前行为 | 修正目标 |
| --- | --- | --- |
| 手机筛选中断 | 每选一项关闭侧栏 | 连续选择后主动查看结果 |
| 条件不可见 | 条件散在各筛选组 | 集中展示，可逐项撤销 |
| 控件位置过深 | 章节长目录排在筛选之前 | 先筛选，后浏览章节 |
| 抽屉上下文丢失 | 背景能滚动，焦点可能留在屏外 | 锁定背景、约束焦点、关闭后回到入口 |
| 长文手机导航缺失 | 小屏隐藏整份目录 | 提供可用的章节选择 |
| AI 内容难发现 | 学习、职业、数字生活分散 | 明确专题入口，沿用就地长文阅读 |

| 层级 | 入口 | 统一行为 |
| --- | --- | --- |
| 概览 | 页头与专题入口 | 说明内容范围，进入专题长文 |
| 检索 | 搜索、筛选、章节 | 保持结果计数与条件一致 |
| 细读 | 条目目录与锚点 | 在正文定位并保留可分享地址 |
| 长解释 | 长文链接 | 就地阅读，关闭后返回原位置与焦点 |
