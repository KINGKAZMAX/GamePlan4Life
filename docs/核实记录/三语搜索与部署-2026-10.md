# 三语界面、关键词搜索与部署

日期：2026-10-29。用户要求增加关键词搜索栏、简体/繁体/英文 UI，并更新部署上线。

## 实现范围

- 首页标题之后放置显式关键词搜索栏，配搜索按钮、清除按钮和常用主题入口。
- 首页与固定顶栏搜索框共用查询状态。输入法组合期间不提前检索，切换语言前保留尚未提交的输入。
- `ui-i18n.js` 提供 256 个三语界面文案键、53 节导航名称、六篇分类与筛选标签。
- 语言可在简体中文、繁體中文、English 之间切换，并保存在本机和 URL 的 `lang` 参数中。
- 只翻译界面。正文、长文及原始来源不做整页自动替换，并在搜索栏旁明确说明。
- 常见繁体与英文主题词按明确别名检索简体正文。例如 design/設計 对应设计，animation/動畫 对应动画。未知词保留原样。
- 离线构建内联语言模块，移动离线 HTML 文件后仍可切换语言，不依赖外部翻译服务。

## 验证

- `node tools/check-i18n.mjs`：104 个页面使用的文案键、53 节导航、语言持久化和事件、查询别名通过。
- 独立词典检查：256 个键在三种语言中完整一致；URL、已存偏好、默认简体的优先级通过，禁用存储仍可切换。
- `node tools/check-parser.mjs`：1117/1117 条完整，英文词边界和中文检索通过。
- `node tools/check-plain.mjs`：1117 条，0 条不合格。
- `node tools/check-refs.mjs --check`：967 处通过，旧引用未漂移。
- 375、768、1440 像素宽度分别验证三语显示、无页面横向溢出、两搜索框同步、繁英别名、查询和语言保持、专题阅读与小屏筛选。
- 浏览器断网打开离线版，英文 UI、英文查询和新专题均可用。
- `node tools/offline/build.mjs`、`npm --prefix tools/epub run build` 构建通过。
- 独立审查未发现阻止上线的重要缺陷。审查指出的错误提示切换语言细节已补入动态文案标记。

浏览器截图与执行结果保存在忽略目录 `dist/qa/languages/`。
